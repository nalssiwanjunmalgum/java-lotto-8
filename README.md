# java-lotto-precourse

## 학습 목표
- 관련 함수를 묶어 클래스를 만들고, 객체들이 협력하여 하나의 큰 기능을 수행하도록 한다.
    - (도전) 객체들의 협력을 담는 하나의 클래스를 기획해보자
- 클래스와 함수에 대한 단위 테스트를 통해 의도한 대로 정확하게 작동하는 영역을 확보한다.
    - (도전) 클래스, 함수 단위 별 단위 테스트를 진행하면서 전체적인 커버 범위를 넓혀보자
- 2주 차 공통 피드백(디스코드 참고)을 최대한 반영한다.
    - README.md를 상세히 작성한다
    - 기능 목록을 재검토한다
    - 기능 목록을 업데이트한다
    - 값을 하드 코딩하지 않는다
    - 구현 순서도 코딩 컨벤션이다
    - 변수 이름에 자료형은 사용하지 않는다
    - 한 메서드가 한 가지 기능만 담당하게 한다
    - 메서드가 한 가지 기능을 하는지 확인하는 기준을 세운다
    - 테스트를 작성하는 이유에 대해 본인의 경험을 토대로 정리해본다
    - 처음부터 큰 단위의 테스트를 만들지 않는다

## 기능 요구 사항
- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다 -> *LottoNumbers*
    - [ ] Lotto는 중복되지 않는 6개의 숫자를 포함한다
    - [ ] 각각의 수는 1이상 45이하이다

- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
    - 당첨 번호는 사용자로부터 입력받은 번호를 의미한다
    - [ ] *LottoCandidate* 중복되지 않는 숫자 6개를 입력받아야 한다
    - [ ] *LottoCandidate* 보너스 번호 1개를 입력받는다
    - [ ] *LottoCandidate* 는 LottoTicket(6개의 중복 없는 수) 그리고 보너스 번호 1개로 구성되어 있다

- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
    - 만족하는 조건 <-> 지급되는 금액
        - 조건은 로또 번호 2개를 인자로 받고 몇 개의 번호가 일치하는지를 반환한다
        - 조건에 따라 지급되는 금액을 설정한다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원

- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
    - 구입 금액을 1000으로 나눈 몫만큼 로또를 발행할 수 있다
- **입력** 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
    - 당첨 내역은 몇 개가 일치하는지, 지급 금액은 어떻게 되는지를 가지고 있다
    - 최종적으로 구입 금액 대비 수익에 대한 %(percentage)를 출력한다
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.
    - (도전) Exception의 종류별 역할 그리고 특징은 어떤지 생각해야 한다
    - Enum 타입으로 예외 유형을 구분한다
